Run your own

Run a match in five minutes

The harness is open source and every game we played is in a public dataset: transcripts, private whispers, reasoning, belief probes and the cost of every API call.

Quick start

git clone https://github.com/…/clocktower && cd clocktower
pip install -e .                       # Python 3.11+
export ANTHROPIC_API_KEY=... OPENAI_API_KEY=...
python -m unittest discover -s tests   # rules and engine tests, no API calls
python -m clocktower sim --games 200   # random players, no API: check the Storyteller

Play one side-swapped pair

python -m clocktower run --good-model claude-opus-5-5 --evil-model gpt-6.1-sol \
    --games 1 --swap --seed 1 --out games/v17/demo
python -m clocktower replay games/v17/demo/game-01 --thinking     # read it

Each game writes transcript.md (an omniscient replay with every seat's reasoning), events.jsonl, probes.jsonl (belief probes), calls.jsonl (every API call with tokens and cost), config.json and result.json. A game costs from about $2 to $50 depending on the models.

Run a tournament and rate it

python -m clocktower plan plans/models-2026.json --within 10 --pairs 1 \
    --seed 120000 --out games/v17/mine > plans/mine.json
python -m clocktower tournament plans/mine.json      # every game at once; rerun to resume
python -m clocktower analyze games/v17/mine-*/game-* # win rates, probes, quick ratings
python -m clocktower ratings                         # the Bradley–Terry fit with bootstrap intervals

Use the existing games

python -m clocktower fetch v17/f3-*      # download logs from the dataset
python -m clocktower.export --games games  # rebuild this website from them

Mixed teams (--good-model A,B), one upgraded seat (--seat-model good:MODEL:1) and a different model for the Imp (--seat-model Imp:MODEL) are all built in. The full protocol is in docs/PROTOCOL.md; why each rule is what it is, in docs/protocol-history.md.

Questions worth exploring

  • Learning over time. Do models get better across games? In context (notes carried between games) or by fine-tuning on their own logs. Careful: shared notes on the good team leak who is good, so evil-only learners or a league of individual agents are the clean designs.
  • Harder scripts. Trouble Brewing is the beginner script. Characters like the Lunatic (who believes they are the Demon) or scripts with more misinformation would test whether models can reason about information that is wrong on purpose.
  • One smart player. How much does a single strong model lift a team of weaker ones, as good and as evil? Which evil role carries the team?
  • Mixed teams, systematically. We found half-and-half evil teams play worse than either model alone. Is that coordination cost, or style mismatch? Does it shrink with stronger models?
  • Teammate recognition. Writing style alone separates the teams in our logs, though no model ever used it. Do models learn to fingerprint their teammates, and does uniform typography stop it?
  • Humans vs AIs. Seat humans at the table (it's built in) for a human baseline, and to see whether people can tell which players are models.
  • Thinking on votes. Claude models skip thinking on most votes as good, and unthinking votes follow the running tally more. Forcing a thought before each vote is a cheap ablation.
  • Memory. Models that carry their own reasoning across turns vs replies only: how big is the handicap?
